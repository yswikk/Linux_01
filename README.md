# Установка и настройка Ubuntu Server

##  Описание

Этот проект представляет собой руководство по установке и базовой настройке **Ubuntu 20.04 Server LTS** без графического интерфейса на **VirtualBox**. В ходе выполнения проекта были рассмотрены ключевые аспекты работы с операционной системой Linux, включая настройку пользователей, конфигурацию сети, работу с файловой системой и службами.

## 🔧 Основные этапы

1. **Установка ОС**:
   - Установка **Ubuntu 20.04 Server LTS** в VirtualBox без графического интерфейса.
   - Проверка версии ОС после установки.

2. **Создание пользователя**:
   - Добавление нового пользователя и включение его в группу `adm`.

3. **Настройка сети**:
   - Изменение имени хоста.
   - Настройка часового пояса.
   - Определение IP-адресов и шлюза.
   - Конфигурация статического IP-адреса.
   - Проверка соединения через `ping`.

4. **Обновление ОС**:
   - Установка и обновление системных пакетов.

5. **Настройка sudo**:
   - Добавление пользователя в `sudoers`.
   - Использование `sudo` для изменения параметров системы.

6. **Служба времени**:
   - Включение и проверка синхронизации времени через NTP.

7. **Работа с текстовыми редакторами**:
   - Установка и работа с `vim`, `nano`, `mcedit`.

8. **Установка и настройка SSH**:
   - Установка OpenSSH.
   - Изменение стандартного порта.
   - Проверка доступности службы.

9. **Мониторинг системы**:
   - Использование `top`, `htop`.
   - Просмотр списка процессов.
   - Анализ загрузки процессора и памяти.

10. **Работа с файловой системой**:
    - Использование `fdisk`, `df`, `du`.
    - Определение размера дисков и каталогов.

11. **Системные логи**:
    - Просмотр логов `/var/log/dmesg`, `/var/log/syslog`, `/var/log/auth.log`.

12. **Планировщик задач (cron)**:
    - Запуск команд через `cron`.
    - Просмотр запланированных задач.
